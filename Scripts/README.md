# S.O.R.N. - C++ Script Contributions

This section showcases selected C++ scripts from S.O.R.N., an Unreal Engine project developed collaboratively by a team of developers.

I contributed to several gameplay, UI, and player settings systems, focusing primarily on input sensitivity, accessibility features, mouse behavior, and player-configurable settings.

Please note: The scripts included in this section are part of a shared codebase and were not written entirely by me. Some systems contain contributions from multiple team members. The documentation below highlights the specific features, improvements, and bug fixes that I personally worked on.

The purpose of this section is to demonstrate my contributions to the project's C++ development while providing context for the larger systems they belong to.
